启用联网搜索时，您的搜索关键词会发送到公开搜索引擎，例如 Bing、百度、360、DuckDuckGo、Brave。被打开的网页会收到您的 HTTP 请求，可能记录您的 IP 地址、User-Agent、访问时间等信息。搜索结果和网页内容随后可能被发送给模型服务商，用于生成回答。

使用图片分析功能时，本软件会把本地图片转换为 base64，并发送给您当前配置的聊天模型服务商，用于视觉理解。请勿分析您无权处理的他人照片或包含敏感信息的图片。

3.6 模型下载

从 Hugging Face 搜索和下载模型时，请求会发送到 huggingface.co 或镜像 hf-mirror.com。这些网站可能记录您的 IP 地址、User-Agent、请求的模型仓库和文件。若您填写了 Hugging Face Token，Token 会随请求发送给 Hugging Face。
