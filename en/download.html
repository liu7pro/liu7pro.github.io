Installation

  1. Download DomeOS-AI-Setup.exe;
  2. Run it and follow the steps;
  3. Configure model services on first launch; see Model services;
  4. If something goes wrong, check the FAQ.

Upgrade & uninstall

Install the new version over the old one; sessions and settings are preserved. To uninstall, remove DomeOS AI from Windows “Settings → Apps”, then delete %LOCALAPPDATA%\DomeOS if you also want to remove your data.
