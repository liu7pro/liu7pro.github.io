Overview

DomeOS AI Agent is a Windows desktop client for AI agents. This version is a native rewrite built on WinUI 3 and Windows App SDK, replacing the web rendering pipeline with native XAML.

Faster startup, lower memory, and window materials, controls and input that match Windows.

Version: v2.0 “Darling”, released 2026-10-30.

System requirements

ItemRequirement
OSWindows 10 1809 (17763) or later, or Windows 11
Architecturex64
DiskInstaller ~526 MB, plus space for the app and data
NetworkAccess to your model endpoint when using cloud models
RuntimeWindows App Runtime 1.7+ (if not bundled)

High DPI, multi-monitor setups and touchpad gestures are supported.

Download & install

  1. Get the latest installer DomeOS-AI-Setup.exe from the download page or Releases;
  2. Run the installer and follow the steps;
  3. If SmartScreen appears, choose “More info → Run anyway”;
  4. Launch the app from the Start menu or the desktop shortcut.

To upgrade, run the new installer over the old version. Sessions and settings are preserved.

First launch

  1. Launch the app and choose a theme (System / Light / Dark);
  2. Open “Settings → Model services” and add a provider;
  3. Choose a default model and test the connection;
  4. Return to the main window and start a new chat.
Tip: No cloud API key? Connect to a local Ollama instance and run the model on your machine.

Model services

Built-in presets plus fully custom endpoints:

  • Presets: OpenAI, Anthropic, Google Gemini, Ollama and OpenAI-compatible APIs;
  • Custom setup: Base URL, protocol and model name;
  • Multiple providers: keep several configured and switch per task.
# Local Ollama example
Base URL: http://127.0.0.1:11434
Model: llama3.1
API key: leave empty

If the connection fails, check the URL, network access, API key and model permissions in that order.

Sessions & tools

  • Multi-session: create, rename, search and archive conversations;
  • Tool calls: every step of the agent's reasoning and calls is shown in a structured view, and sensitive actions ask for confirmation;
  • Code & math: syntax-highlighted code blocks with one-click copy, full Markdown and math rendering;
  • Tray resident: the app keeps running in the tray after you close the window, with a global shortcut to summon it.
Tip: Shortcuts can be reviewed and changed in Settings. If a shortcut conflicts with another app, DomeOS will tell you.

Data & migration

Settings and sessions live in:

%LOCALAPPDATA%\DomeOS
  • To move to a new device, copy that folder and your sessions and settings come with it;
  • To uninstall, remove the app and that folder;
  • Conversation content is only sent to the model provider you configured, never through a relay server.

Please also review the privacy policy of your model provider.

FAQ

Windows says the installer is untrusted

This is the usual SmartScreen prompt for apps without broad distribution. If you trust the source, choose “More info → Run anyway”. Managed devices may require an administrator policy.

The app fails to start or reports a missing runtime

Check that your Windows version meets the requirements and install Windows App Runtime 1.7+, then try again. Running once as administrator can also help.

The model connection fails

Check the endpoint URL, proxy, API key and model name. With local Ollama, make sure the service is running and the port is free.

Where is my data stored?

By default in %LOCALAPPDATA%\DomeOS. You can view the exact path in Settings, or copy the folder for migration and backup.

How do I report a problem?

Open an issue on GitHub Issues with reproduction steps, your Windows version and relevant logs.
