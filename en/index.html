What it does

More than a chat window. Sessions, tool calls and code rendering all happen on the desktop.

Native WinUI 3

The interface is rebuilt with native XAML, so windows, controls and input all behave like system apps.

MCP tool calls

File access and command execution are shown as they happen, with results folded back into the conversation.

Streaming chat

Answers stream in word by word and can be stopped at any time, so long replies stay readable.

Light on resources

Keep it in the tray after closing the window and summon it with a global shortcut.
