Features

Native UI, light footprint

The interface layer is rebuilt with WinUI 3 and Windows App SDK. Startup, memory and interaction all work the Windows way.

Native Windows experience

Native XAML replaces the web rendering pipeline, so windows, controls and input are truly native.

  • Mica / AcrylicBlends with the Windows 11 visual language; the window follows your desktop.
  • System themeLight, dark and accent colors update in real time.
  • Native inputContext menus, drag and drop, touchpad gestures and IME, all native.
  • High DPI & multi-monitorSharp at any scaling ratio.
  • AccessibilityNarrator, full keyboard navigation and UI Automation.

Light and portable

No installer, no MSIX, no certificates. The app and your data stay where you can see them.

  • Single-file distributionDownload one EXE and run it from anywhere.
  • Your data, your folderConfig and sessions live in %LOCALAPPDATA%\DomeOS and move with the folder.
  • Clean uninstallDelete the folder and you're done.
  • In-place upgradeReplace the old file; data and settings stay.

Full agent capabilities

More than a chat window. Sessions, tool calls and code rendering all happen on the desktop.

  • Streaming chatToken-by-token rendering that stays smooth on long replies.
  • Multi-sessionHistory, rename, search and archive.
  • Tool-call visualizationEvery step of the agent's reasoning and calls, structured.
  • Code highlightingNative rendering with one-click copy.
  • Markdown & mathFull rendering support.
  • Tray residentGlobal shortcut to summon the sidebar anytime.
