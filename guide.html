概览

DomeOS AI Agent 是 AI Agent 的 Windows 桌面客户端。当前版本基于 WinUI 3 与 Windows App SDK 原生重写，用原生 XAML 替换了 Web 渲染管线。

启动更快、内存占用更低，窗口材质、控件与输入方式都与 Windows 保持一致。

版本：v2.0 “Darling”，发布于 2026-10-30。

系统要求

项目要求
操作系统Windows 10 1809（17763）及以上，或 Windows 11
架构x64
磁盘空间安装包 约 526 MB，另需预留应用与数据空间
网络使用云端模型服务时需要可访问对应接口
运行库Windows App Runtime 1.7+（若安装包未自带）

高 DPI、多显示器与触控板手势均已适配。

下载与安装

  1. 在 下载页 或 Releases 获取最新安装包 DomeOS-AI-Setup.exe；
  2. 双击运行安装程序，按提示完成安装；
  3. 如果出现 SmartScreen 提示，选择「更多信息 → 仍要运行」；
  4. 安装完成后，从开始菜单或桌面快捷方式启动。

升级时直接运行新版本安装包覆盖安装即可，会话与配置会保留。

首次启动

  1. 启动应用，选择界面主题（跟随系统 / 浅色 / 深色）；
  2. 进入「设置 → 模型服务」，添加一个服务商；
  3. 选择默认模型，点击测试连接确认可用；
  4. 回到主界面，新建会话开始对话。
提示：没有云端 API 密钥时，可以连接本机 Ollama，模型会在本地运行。

模型服务

应用内置多服务商预设，也支持完全自定义的接口：

  • 预设服务商：OpenAI、Anthropic、Google Gemini，以及 Ollama 与 OpenAI 兼容接口；
  • 自定义配置：可填写 Base URL、协议与模型名称；
  • 多服务并存：不同任务可以使用不同模型，随时切换。
# Ollama 本地示例
接口地址: http://127.0.0.1:11434
模型名称: llama3.1
API Key: 留空

连接失败时，依次检查接口地址是否完整、网络是否可达、密钥是否有效、模型是否已开通。

会话与工具

  • 多会话管理：创建、重命名、搜索与归档历史会话；
  • 工具调用：Agent 的每一步思考与调用会以结构化形式展示，敏感操作需要确认；
  • 代码与公式：代码块高亮并支持一键复制，Markdown 与数学公式完整渲染；
  • 托盘常驻：关闭主窗口后仍在托盘运行，可通过全局快捷键唤起。
提示：快捷键可在设置中查看与修改；若与系统或其他软件冲突，应用会给出提示。

数据与迁移

配置与会话统一存放于：

%LOCALAPPDATA%\DomeOS
  • 迁移到新设备时，复制该目录即可保留会话与配置；
  • 卸载时删除应用与上述目录即可清理干净；
  • 对话内容只会在请求模型时发送给所选服务商，不经过中转服务器。

请同时留意所使用模型服务商的隐私政策。

常见问题

安装时提示不受信任

这是 Windows SmartScreen 对未广泛分发应用的常规提示。确认来源可靠后，选择「更多信息 → 仍要运行」。

启动失败或提示缺少运行库

请确认系统版本满足要求，并安装 Windows App Runtime 1.7+ 后重试。若仍然失败，尝试以管理员身份运行一次。

模型连接失败

检查接口地址、网络代理、API Key 与模型名称。使用 Ollama 时，请确认本地服务已在运行，且端口未被占用。

数据存放在哪里

默认位于 %LOCALAPPDATA%\DomeOS。可在设置中查看具体路径，或整体复制用于迁移备份。

如何反馈问题

请在 GitHub Issues 中说明复现步骤、系统版本与相关日志。
