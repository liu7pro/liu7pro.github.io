功能特性

原生界面，轻量运行

界面层基于 WinUI 3 与 Windows App SDK 重写，启动、内存与交互都按 Windows 的方式工作。

原生 Windows 体验

用原生 XAML 替换 Web 渲染管线，窗口、控件与输入都是系统原生的。

  • Mica / Acrylic 材质与 Windows 11 视觉语言融合，窗口背景跟随桌面。
  • 跟随系统主题亮色、暗色与强调色实时切换，无需手动设置。
  • 原生控件与输入右键菜单、拖放、触控板手势与 IME 输入全部原生。
  • 高 DPI 与多显示器不同缩放比例下依然清晰锐利。
  • 无障碍支持Narrator、键盘全导航与 UI Automation 完整接入。

轻量、可迁移

没有安装程序，没有 MSIX，没有证书。应用和数据都在你能看见的地方。

  • 单文件分发下载一个 EXE，放在哪里都能运行。
  • 数据自持配置与会话存放于 %LOCALAPPDATA%\DomeOS，可随文件夹整体迁移。
  • 干净卸载删除文件夹即完成卸载，不留残余。
  • 覆盖式升级新版本覆盖旧文件，数据与配置不动。

完整的 Agent 能力

不只是聊天窗口。会话、工具调用与代码渲染都在桌面端完成。

  • 流式对话逐 token 渲染，长回复滚动依旧流畅。
  • 多会话管理历史、重命名、搜索与归档。
  • 工具调用可视化结构化展示 Agent 的每一步思考与调用。
  • 代码块高亮原生渲染，一键复制。
  • Markdown / 数学公式完整渲染支持，排版清晰。
  • 托盘常驻全局快捷键唤起，随时呼出侧边栏。
